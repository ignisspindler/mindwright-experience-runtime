# Manifests

> **Spoilers.** Every file in this folder contains sealed material: the hidden architecture, attractors, invariants and secrets of an Experience. If you might take part in one, don't read on.

## `pilot/`

Twelve draft manifests, one for each operative architecture, written at rung S3 (Invariants / Secrets) and deliberately thin. The pilot derives S0, S1 and S2 from each by truncation, so a ladder never changes its setting or wording. None of them uses the optional dimensions (scaffolding, mechanisms and operators, expectation, realization).

They are unregistered drafts: `id` and `digest` are null. A manifest receives a MindWright code only when it is registered, and never changes after that.

## Checking a manifest

```bash
node tools/validate.js manifests/pilot
node tools/project.js manifests/pilot/<name>.json --rung S2
```
